Build a GitHub-compatible git forge for the make.fun competition github-core-clone-01: a standalone single-process program (Node, standard library only, no git binary, no network) that serves git smart HTTP (upload-pack protocol v2, receive-pack v0) for clone/fetch/push, the GitHub REST v3 API under /api/v3 (repositories, contents, labels, issues, pull requests with squash merge), the GraphQL v4 API at /api/graphql (including the introspection surface gh and github-mcp-server rely on), and a Model Context Protocol endpoint at /mcp (JSON-RPC tools: create_repo, get_repo, create_issue, list_issues, create_pull_request, merge_pull_request) acting on the same store as REST. The program binds an ephemeral port, registers it with the harness env at $MAKEFUN_ENV_URL/register, long-polls /done and exits 0 when the suite finishes. Everything must be deterministic: no wall clock and no unseeded randomness in any served byte. Start from the kit starter, run the kit's local grader (grade-local, process driver) against the practice instance, and iterate until the conformance, agent-native and performance columns are as high as they can go.
